Repository Structure

Every major directory and the load-bearing files inside it. Written for an engineer's first day on the project.

Top level

PathPurpose
CMakeLists.txtTop-level build: includes cmake/common.cmake, defines the backend targets, adds tools/simulator/, registers the integration CTest (UNIX only), defines format/format-check/lint targets.
cmake/common.cmakeShared toolchain setup: C++20, Release default, OLV_BUILD_TESTS/OLV_WERROR options, Homebrew prefix auto-detection, Boost ≥ 1.74 (CONFIG mode), and the INTERFACE targets olv_proto, olv_test_support, olv_warnings.
cmake/open_dis_cpp.cmakeLocates the installed open-dis-cpp prefix and exposes the imported static target open_dis_cpp (headers marked SYSTEM).
LICENSE / THIRD_PARTY.mdMIT license; complete dependency & license table, asset provenance, air-gap notes.
.clang-format / .clang-tidy / .editorconfig Style configuration — see Coding Standards.
.dockerignoreKeeps host artifacts (notably build*/ with its stale CMakeCache) out of container build contexts.

Backend: include/, src/, test/, tools/

PathPurpose
include/olv/protocol.hppSingle source of truth for the OLV1 wire format: constants, ObjectRecord/StatePacket, DecodeError, CRC-32, encode()/decode(). Header-only; shared by backend, simulator, and tests via the olv_proto target.
include/olv/toml.hppFirst-party TOML-subset parser (header-only), mirrored by frontend/js/toml.js.
include/olv/dis_entity_id.hppparseDisEntityId() — the one shared parser for "site:app:entity" strings, used by backend config, DIS input source, and the simulator so the format can't diverge.
src/main.cppolv_backend entry point: config → logger → StateStore → InputSource → WsServer wiring, signal handling.
include/olv/config.hpp + src/config.cppCLI + TOML parsing with shared range validation; two-pass argument handling (--config first, then flags).
include/olv/logger.hpp + src/logger.cppThread-safe file logger, ISO-8601 timestamps, level filtering, optional stderr mirroring.
include/olv/state_store.hpp + src/state_store.cppThe single mutex-protected shared state: object table, satellite, counters, snapshot-with-pruning.
include/olv/input_source.hpp + src/input_source.cppInputSource strategy interface + makeInputSource() boot-time factory.
include/olv/olv1_input_source.hpp + src/olv1_input_source.cppDefault input thread: async UDP receive → proto::decode → StateStore::apply.
include/olv/dis_input_source.hpp + src/dis_input_source.cppDIS input thread: manual header parse, open-dis-cpp unmarshal, EntityID fold, satellite carry-forward, per-entity timestamp staleness.
include/olv/json_writer.hpp + src/json_writer.cppSnapshot → WS JSON text (hello + state), row-array encoding, fixed rounding.
include/olv/ws_server.hpp + src/ws_server.cppBeast acceptor, sessions, 1 Hz broadcast timer, per-session 5-frame outbox.
tools/ws_probe.cppolv_ws_probe: standalone WS capture client for the integration test (links only Boost).
test/Seven unit-test files compiled into olv_backend_tests — see Testing.
test/support/olv_test.hppThe shared (backend + simulator) ~120-line C++ test framework (registration macros, check macros, runner).

tools/simulator/

PathPurpose
src/main.cppCLI entry: arg parsing, socket setup (IPv4-preferring hostname resolution), paced send loop, loop/duration handling.
src/csv_reader.{hpp,cpp}Strict CSV parser: exact header check, per-field validation with line numbers, name-or-number object types.
src/frame_builder.{hpp,cpp}Groups rows into frames by time_s, carries the satellite forward, chunks into ≤128-object StatePackets with monotonic sequence.
src/generator.{hpp,cpp}Deterministic LCG-seeded synthetic world: circular-orbit satellite + mixed object population, analytic velocities.
src/dis_builder.{hpp,cpp}Frame → DIS Entity State PDUs (big-endian, one per entity, satellite first).
src/sim_config.{hpp,cpp}CLI + TOML parsing for the simulator; DIS destination-port defaulting.
data/example_mission.csv61-frame bundled mission (regenerable via scripts/make_example_csv.py, fixed seed).
tests/Four unit-test files → olv_sim_tests.

frontend/

PathPurpose
index.htmlThe single page: canvases, panels, modals; loads js/main.js as an ES module.
config.tomlOptional site defaults (websocket host/port, display toggles) — lenient parsing.
js/16 ES modules. DOM-touching: main.js, ui.js. GL-scoped: renderer.js (+ camera.js, sat_camera.js, atlas.js, textures.js, math3.js). Pure logic (Node-testable): net.js, model.js, settings.js, site_config.js, toml.js, sun.js, sky.js, star_catalog.js. See the source walkthrough.
css/style.cssAll app styling.
assets/Vendored public-domain NASA Earth textures + provenance README with SHA-256 hashes.
dev/smoke.htmlStandalone renderer eyeball page fed by synthetic data — no backend needed.
tests/Eleven node:test suites + validate_message.mjs (the integration test's parser check).

docs/, config/, scripts/, containers/, sbom/

PathPurpose
docs/PLAN.mdThe plan of record: requirements, frozen interfaces, threading model, work breakdown. Normative for design intent.
docs/PROTOCOL_UDP.md / PROTOCOL_DIS.md / PROTOCOL_WS.mdNormative wire-format specs (code wins on conflict; the responsible source file is named in each doc).
docs/features/Per-feature frozen design specs: FEATURE_INPUT_SOURCES.md, FEATURE_SATVIEW.md (v0.3), FEATURE_SKY.md (v0.4).
docs/SBOM.mdSBOM strategy and sample output.
docs/site/This documentation website.
config/Commented example TOML configs matching built-in defaults.
scripts/run_all.sh (compose wrapper), install_open_dis.sh, integration_test.sh, gen_sbom.py, serve_frontend.sh, make_example_csv.py, cleanup.sh, serve_docs.sh.
containers/Containerfile.cpp (multi-stage; targets backend, simulator), Containerfile.frontend (nginx), compose.yaml (three services, bridge network, port env vars).
sbom/Generated CycloneDX 1.5 SBOMs (committed snapshots; regenerate with gen_sbom.py).
