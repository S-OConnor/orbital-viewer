API Documentation

The public programming interfaces: the shared C++ headers, the backend's internal seams, and the frontend's module APIs. Wire protocols and file formats have their own reference pages.

C++ shared headers (olv_proto)

olv/protocol.hpp — namespace olv::proto

constexpr limits
kMagic="OLV1", kVersion=1, kHeaderSize=56, kRecordSize=48, kCrcSize=4, kMaxObjectsPerPacket=128, kMaxTrackedObjects=5000, kMinPacketSize=60, kMaxPacketSize=6204, kMaxCoordinateMeters=1e13.
enum class ObjectType : uint8_t
kDebris=1, kStar=2, kComet=3, kSatellite=4, kGroundHot=5; helpers isKnownObjectType(v), toString(ObjectType).
flags
kFlagHasVelocity=0x01, kFlagHighlight=0x02.
struct ObjectRecord
id (u32), type, flags, confidence (0–100), px/py/pz (double, ECEF m), vx/vy/vz (float, m/s), intensity (float; Kelvin for ground-hot, magnitude for stars); bool hasVelocity() const.
struct StatePacket
sequence, sat_id, sat_px/py/pz, sat_vx/vy/vz, object_total, std::vector<ObjectRecord> objects.
std::vector<uint8_t> encode(const StatePacket&)
Serializes little-endian with trailing CRC-32; truncates >128 objects, clamps confidence to 100 and object_total to 5000.
DecodeError decode(const uint8_t* data, size_t len, StatePacket& out)
Stateless validation pipeline; returns kNone and fills out only on full success. Error order: kTooShort, kTooLong, kBadMagic, kBadVersion, kBadMsgType, kTooManyObjects, kBadLength, kBadCrc, kNonFinite, kOutOfRange, kBadObjectType.
uint32_t crc32(const uint8_t*, size_t)
CRC-32 (IEEE 802.3 reflected, zlib-compatible); compile-time table.

olv/protocol_olv2.hpp — namespace olv::proto::olv2

Header-only, wire format for the OLV2 per-track batched protocol (reference). Reuses proto::crc32, the proto::detail byte helpers, ObjectType, normalizeObjectType, and kMaxCoordinateMeters from olv/protocol.hpp (not modified) rather than duplicating them.

constexpr limits
kMagic={'O','L','V','2'}, kVersion=1, kHeaderSize=24, kPointSize=84, kCrcSize=4, kMaxPoints=25, kMinPacketSize=112, kMaxPacketSize=2128.
enum class MsgType : uint8_t
kTrackUpdate=1.
point flags
kPointSatHasVel=0x01, kPointTgtHasVel=0x02; target flags reuse proto::kFlagHighlight.
struct Point
t (double, UTC epoch seconds), flags, sat_px/py/pz and tgt_px/py/pz (double, ECEF m), sat_vx/vy/vz and tgt_vx/vy/vz (float, m/s); bool satHasVelocity() const, bool tgtHasVelocity() const.
struct TrackPacket
sequence (per-datagram, diagnostic only — not used for staleness), track_id, sat_id, target_type, target_flags, confidence (0–100), std::vector<Point> points (1..kMaxPoints, strictly ascending t).
std::vector<uint8_t> encode(const TrackPacket&)
Serializes little-endian with trailing CRC-32; truncates beyond 25 points, clamps confidence to 100, masks flags to their defined bits. Does not validate time ordering (the receiver does).
DecodeError decode(const uint8_t* data, size_t len, TrackPacket& out)
Stateless validation pipeline; returns kNone and fills out only on full success. Error order: kTooShort, kTooLong, kBadMagic, kBadVersion, kBadMsgType, kBadPointCount, kBadLength, kBadCrc, kNonFinite, kOutOfRange, kBadTime. Per-track staleness (item 11 of the spec) is not checked here — it's stateful and lives in Olv2InputSource.
const char* toString(DecodeError)
snake_case reason strings, matching OLV1's toString(DecodeError) where the reason is shared (e.g. "bad_crc", "out_of_range").

olv/toml.hpp — namespace olv::toml

struct Value { Type type; std::string s; int64_t i; double f; bool b; }
Type is kString | kInteger | kFloat | kBoolean; typeName() for error text.
struct ParseResult
std::map<std::string, Value> values keyed as flattened "table.key"; error, error_line (1-based), ok().
parse(std::istream&) / parse(const std::string&) / parseFile(path)
Grammar: comments, one-level [table], bare keys, double-quoted strings (escapes \" \\ \n \t \r), bools, ints, floats (no exponent). Everything else rejects with a line-numbered error. See the grammar reference.

olv/dis_entity_id.hpp

bool parseDisEntityId(std::string_view, uint16_t& site, uint16_t& app, uint16_t& entity)
Parses "site:application:entity" — exactly three colon-separated decimal uint16s. Shared by backend config, DisInputSource, and the simulator so the format cannot diverge.

Backend internal interfaces

class InputSource { virtual void start(); virtual void stop(); }
Strategy interface for the intake path; both methods idempotent. Implemented by Olv1InputSource, DisInputSource, and Olv2InputSource; each owns a private io_context + thread.
std::unique_ptr<InputSource> makeInputSource(const Config&, StateStore&, Logger&)
Boot-time factory switching on Config::input_mode (kOlv1 default / kDis / kOlv2).
class StateStore
StateStore(std::chrono::seconds expiry); countReceived(bytes); countDropped(DropKind); ApplyResult apply(const StatePacket&, wall_time, mono_time) (sequence gate, satellite replace, object upsert — OLV1/DIS only); void applyTrack(const TrackUpdate&, wall_time, mono_time) (OLV2 only, additive: upserts the target row, replaces the satellite only if the update's sample time is newer than the stored one, appends every trail point to a pending buffer capped at kMaxPendingTrailPoints = 125000; no staleness check — the caller already did it); Snapshot snapshot(mono_time) (prune + full copy, objects sorted by id, and drains the pending trail buffer into Snapshot::trail_points). All methods take the single internal mutex.
class Logger
open(path, LogLevel, mirror_stderr); debug/info/warn/error(component, message) — thread-safe, ISO-8601 UTC ms timestamps, flush per line. parseLogLevel(str) is case-insensitive strict.
class WsServer
WsServer(io_context&, bind, port, StateStore&, Logger&, hz); start()/stop(). Sends hello per connection, broadcasts state at hz; 5-frame per-session outbox.
DisInputSource::processDatagram(const uint8_t*, size_t, const std::string& from)
Public test seam: runs the full DIS pipeline without a live socket; from is used only in log lines.
Olv2InputSource::processDatagram(const uint8_t*, size_t, const std::string& from)
Public test seam, same shape: runs one datagram through count → proto::olv2::decode → per-track staleness → translate → applyTrack, without a live socket; from is used only in log lines.
struct Config / parseArgs(argc, argv, error) / applyConfigFile(...)
Defaults < TOML < flags; strict schema; cross-field DIS invariant (OLV2 has none — every olv2_* key has a sensible default). Full key/flag tables: Configuration Reference and CLI Reference.

Frontend module APIs

net.js — parseStateMessage(text) → {type, ...}
Throws on any protocol violation (bad JSON, unknown type, row length ≠ 11, unknown category, partial velocity, hello protocolVersion ≠ 1). Categories map 1→debris, 2→star, 3→comet, 4→satellite, 5→groundHot. Also parses the optional trailPoints array (present only in OLV2 mode): absent → []; present rows must be 5-element, all-finite, or the message is rejected.
net.js — createConnection({host, port, onState, onHello, onStatus, wsFactory})
connect(), close(), setEndpoint(host, port) (immediate reconnect), getParseErrorCount(). Backoff 1/2/4/8/10 s; parse errors counted, connection kept.
model.js — createModel()
applyState(msg), getSnapshot() (incl. serverTime and trailPoints, default []), getListRows(filter, cap=1000), getCounts(), getStats(), secondsSinceLastState().
settings.js — createSettings(storage, siteDefaults)
get() (deep clone), update(patch) (validate/clamp/persist/notify), onChange(cb), resetDefaults(). Settings: showTrails=false, trailSeconds=30 (0–60), showLabels=false, showSky=true, viewMode='orbit'|'sat', categories{5×true}, host='', port=8765 (1–65535). Storage key olv.settings.v1.
site_config.js — loadSiteConfig(fetchFn) → Promise<object>
Fetches config.toml; validates against the 5-key schema (websocket.host/port, display.show_trails/trail_seconds/show_labels); any failure resolves {}.
renderer.js — createRenderer(glCanvas, overlayCanvas)
setSnapshot(snap), setSettings(s), setSelected(id|null), frame(nowMs), resize(), pick(x, y) → id|null (12 px radius, view-mode aware). Throws if WebGL is unavailable. setSnapshot's trailPoints rows (OLV2 only) feed a 512-sample server-fed trail per id, instead of the default 64-sample client-built ring.
sat_camera.js
satViewMatrix(posUnits, velUnits) → Float32Array(16)|null (nadir boresight, velocity screen-up, fallback chain velocity→north→+X); fisheyeProjectNdc(view, world, aspect, fovDeg) → {x,y,depth,theta}|null; constants SAT_FOV_DEG=170, SAT_NEAR=0.05, SAT_FAR=1000. Lockstep: must match the renderer's FISHEYE_GLSL byte-for-byte in behavior.
sky.js / sun.js
sunDirectionEcef(dateOrMs), gmstRad(ms), raDecToEci(ra, dec), eciToEcef(v, gmst), moonDirectionEcef(ms), moonIlluminatedFraction(ms), planetsEcef(ms) (PLANET_NAMES = mercury/venus/mars/jupiter/saturn), starsEcefInto(ms, out) (allocation-free), STAR_COUNT, STAR_MAGS. Precision class ~arcmin–0.5°.
toml.js — parseToml(text) → object
JS mirror of the C++ grammar; throws with line numbers on rejected constructs.

Test framework (test/support/olv_test.hpp)

This first-party framework now backs only olv_sim_tests (incl. test_olv2_builder.cpp). olv_backend_tests — every file under test/, including the OLV2 files test_protocol_olv2.cpp and test_olv2_input_source.cpp — runs on GoogleTest (TEST(Suite, case), EXPECT_*/ASSERT_*, gtest_discover_tests) instead, a repo-wide migration that predates OLV2.

OLV_TEST(name) { ... }
Declares, registers (static-init), and defines a test case.
OLV_CHECK(cond) / OLV_CHECK_EQ(a,b) / OLV_CHECK_NEAR(a,b,eps)
Non-fatal checks; failures print FAIL file:line and mark the case failed but keep executing.
OLV_TEST_MAIN()
Defines main() — exactly one per test binary. Runner supports --list; prints [ RUN ]/[ OK ]/[ FAIL ] and a summary; exit 0 iff all pass.

Custom enums streamed in checks need an operator<< in their own namespace (ADL) — see existing test files for the pattern.

Worked examples

Encode and send an OLV1 packet (C++)

#include "olv/protocol.hpp"
using namespace olv::proto;

StatePacket pkt;
pkt.sequence = 1;
pkt.sat_id = 1;
pkt.sat_px = 6921000.0; pkt.sat_py = 0.0; pkt.sat_pz = 0.0;
pkt.sat_vx = 0.f; pkt.sat_vy = 7600.f; pkt.sat_vz = 0.f;

ObjectRecord r{};
r.id = 101; r.type = ObjectType::kDebris;
r.flags = kFlagHasVelocity; r.confidence = 90;
r.px = 6921000.0; r.py = 50000.0; r.pz = 0.0;
r.vx = 0.f; r.vy = 7500.f; r.vz = 100.f;
pkt.objects.push_back(r);
pkt.object_total = 1;

std::vector<uint8_t> wire = encode(pkt);   // 56 + 48 + 4 = 108 bytes
// sendto(sock, wire.data(), wire.size(), ...) toward port 47000

Encode and send an OLV2 track datagram (C++)

#include "olv/protocol_olv2.hpp"
using namespace olv::proto::olv2;

TrackPacket pkt;
pkt.sequence = 1;
pkt.track_id = 2001;         // becomes the WS object id
pkt.sat_id = 1;
pkt.target_type = 1;         // ObjectType::kDebris
pkt.confidence = 95;

Point p;
p.t = 1790000000.125;        // UTC epoch seconds
p.flags = kPointSatHasVel | kPointTgtHasVel;
p.sat_px = 6921000.0; p.sat_py = 0.0;     p.sat_pz = 0.0;
p.tgt_px = 6923371.4; p.tgt_py = 12000.0; p.tgt_pz = -55000.2;
p.sat_vx = 0.f; p.sat_vy = 7600.f; p.sat_vz = 0.f;
p.tgt_vx = 0.f; p.tgt_vy = 7611.f; p.tgt_vz = 0.f;
pkt.points.push_back(p);      // 1..25 points per datagram; disjoint batches — never resend a point

std::vector<uint8_t> wire = encode(pkt);   // 24 + 84*1 + 4 = 112 bytes
// sendto(sock, wire.data(), wire.size(), ...) toward port 47002

Consume the WebSocket feed (JavaScript, outside the app)

import { parseStateMessage } from './frontend/js/net.js';

const ws = new WebSocket('ws://localhost:8765/');
ws.onmessage = (ev) => {
  const msg = parseStateMessage(ev.data);   // throws on protocol violations
  if (msg.type === 'state') {
    console.log(msg.stats.objectCount, 'objects at', msg.serverTime);
  }
};
