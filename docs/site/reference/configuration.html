Configuration Reference

Every configuration key, environment variable, and persisted setting. Precedence everywhere: built-in defaults < config file < explicit overrides (CLI flags / saved browser Settings). Backend and simulator are strict (unknown key, wrong type, or out-of-range aborts startup with key + line); the frontend is lenient (warn + defaults).

The dis_*/olv2_* keys are still schema-checked whenever present, regardless of mode. Unlike DIS, OLV2 has no required cross-field key — mode="olv2" alone is runnable on defaults.
