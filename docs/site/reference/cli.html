Scripts

scripts/build_builder.sh

scripts/build_builder.sh [extra build args, e.g. --build-arg X=Y]

Step 1: builds the olv-builder build-environment image (toolchain, Boost, GoogleTest, open-dis-cpp) from containers/Dockerfile.builder, tagged $OLV_BUILDER_IMAGE (default localhost/olv-builder:latest). The only step in the pipeline that needs network access; point OLV_BUILDER_IMAGE at a registry image to skip it.

scripts/build.sh

scripts/build.sh [--clean] [--debug]

Step 2: runs a docker/podman run of olv-builder with the repo bind-mounted at /src (--network none, --security-opt label=disable), configures/builds into build/container/ (tests on, Release by default — --debug for Debug), then cmake --install --component backend|simulator stages the runtime files into build/dist/backend/ and build/dist/simulator/. --clean deletes both trees first.

scripts/test.sh

scripts/test.sh [--unit] [-- <extra ctest args>]

Step 3: runs ctest inside olv-builder against the build tree from scripts/build.sh — nothing is recompiled. --unit passes -LE integration to skip the end-to-end test. On success, stamps build/dist/.tested with checksums of the staged files, which scripts/package.sh checks against.

scripts/package.sh

scripts/package.sh [--untested] [backend|simulator ...]

Steps 4-5: builds the backend/simulator runtime images (default both) from containers/Dockerfile.backend/Dockerfile.simulator, each using its own build/dist/<component>/ directory as the build context. Tags $OLV_BACKEND_IMAGE/$OLV_SIM_IMAGE (default localhost/olv-backend:latest/localhost/olv-sim:latest), labelled with the git revision. Refuses to build from a build/dist that doesn't match the last passing scripts/test.sh run unless --untested is given.

scripts/build_all.sh

scripts/build_all.sh [--clean] [--unit]

Runs steps 1-5 in order (build_builder.sh → build.sh → test.sh → package.sh), stopping at the first failure. Skips step 1 when OLV_BUILDER_IMAGE is already set (a prebuilt/registry builder image). --clean/--unit pass through to build.sh/test.sh.

scripts/run_all.sh

scripts/run_all.sh [--sim] [--ws-port N] [--udp-port N] [--http-port N] [--build] [-- <extra compose args>]

Step 6: containerized bring-up — auto-detects the compose engine (OLV_COMPOSE → podman compose → docker compose → podman-compose → docker-compose), project name olv, exports the port env vars, then up -d the backend and frontend services from containers/compose.yaml using whatever localhost/olv-backend/localhost/olv-sim (or registry) images already exist — it never builds them itself unless --build is given, in which case it runs scripts/build_all.sh first (and adds --build to the compose up, which only affects the compose-built frontend image). --sim adds the compose sim profile so the simulator container also comes up, replaying example_mission.csv on loop; without it only the backend and frontend start. Waits up to 30 s for the WS port, prints URLs, streams logs. Ctrl-C (or any exit) tears the stack down (--profile sim down, so it's safe whether or not --sim was used). Exit 130/143 on INT/TERM; 1 if the backend never comes up (dumps its logs first) or if a needed local image is missing.

scripts/integration_test.sh

scripts/integration_test.sh BACKEND_BIN SIM_BIN PROBE_BIN [REPO_ROOT]

End-to-end test on random ephemeral ports; normally invoked by CTest as the integration test. Prints INTEGRATION PASS / non-zero exit.

scripts/serve_frontend.sh

scripts/serve_frontend.sh [PORT]      # default 8000

Python stdlib HTTP server bound to 0.0.0.0, serving the repo root — open http://localhost:PORT/frontend/.

scripts/serve_docs.sh

scripts/serve_docs.sh [PORT]          # default 8090

Serves this documentation site (docs/site/) and opens the index page in your default browser.

scripts/make_example_csv.py

python3 scripts/make_example_csv.py

Deterministically regenerates tools/simulator/data/example_mission.csv (fixed seed 20260701; 61 frames, fixed object mix).

scripts/cleanup.sh

scripts/cleanup.sh

Stops the compose stack (--profile sim down --remove-orphans, so the simulator container is removed too if it was running), force-stops any olv_* containers, and kills stray run_all.sh / serve_frontend.sh / dev-server processes.

Build-tree quality targets

Run the cmake/ctest lines inside the olv-builder container, the same way scripts/build.sh/test.sh do (e.g. docker/podman run --rm --network none --security-opt label=disable -v "$PWD":/src -w /src localhost/olv-builder:latest ... — see Installation):

cmake --build build/container --target format         # clang-format in place
cmake --build build/container --target format-check   # verify only (--Werror)
cmake --build build/container --target lint           # cppcheck
ctest --test-dir build/container [--output-on-failure] [-R name] [-L label]
node --test "frontend/tests/*.test.mjs"                        # host
node frontend/tests/validate_message.mjs FILE [--min-objects N]  # host
