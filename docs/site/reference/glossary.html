Glossary & Acronyms

Project terms

OLV / Orbital LOS Viewer
This project. "LOS" = line of sight.
OLV1
The first-party binary UDP wire protocol, version 1 (reference).
Primary satellite
The single privileged satellite whose telemetry fills the Satellite panel and whose position the SAT view renders from. Carried in every OLV1 packet header; in DIS mode, promoted by dis_satellite_entity_id.
Tracked object
Any of the up-to-5,000 non-primary objects: unknown, debris, star, comet, satellite, ground-hot.
Ground-hot
Object category 5 — a hot object on Earth's surface, stationary in ECEF; its intensity is a temperature in Kelvin (drives its rendered tint).
Update cycle / frame
One coherent world state at one instant — a satellite state plus an object set. Cycles over 128 objects are split into multiple self-contained packets.
Input source
The backend's boot-selected intake strategy (InputSource): Olv1InputSource (default) or DisInputSource. Exactly one per process.
StateStore
The backend's single mutex-protected shared state: object table, satellite, counters. The only synchronization point in the system.
Snapshot
A pruned, sorted, full copy of the StateStore taken by the broadcast thread each tick; also the frontend's term for the latest parsed state message.
Carry-forward
Two related behaviors: objects persist in the StateStore until expiry even when later packets don't mention them; and in DIS mode (and CSV frames without a sat row), the last-known satellite state is re-stamped into each update.
Expiry window
Objects not refreshed within expiry_seconds (default 15 s) are pruned at snapshot time.
Sequence staleness
The wraparound-safe rule accepting only packets whose sequence is newer than the last accepted one ((int32_t)(seq - last) > 0).
Fold / FNV-1a fold
The deterministic hash compressing a 48-bit DIS EntityID into a 32-bit OLV id (details).
Sat view / SAT mode
The satellite point-of-view render mode: nadir boresight, velocity up, 170° equidistant fisheye (feature v0.3).
Fisheye lockstep
The rule that the GLSL fisheye projection block in renderer.js and the JS math in sat_camera.js must be changed together — picking correctness depends on them agreeing exactly.
Sky feature
The optional celestial background (feature v0.4): ~200 catalog stars, Moon with illuminated fraction, five naked-eye planets, all positioned from serverTime.
Scene clock / scene epoch
The frontend's time base: anchored to each state message's serverTime, advanced smoothly between messages; drives all celestial positions.
Site defaults
Values from frontend/config.toml — the baseline a fresh browser starts from, and what "Reset to defaults" returns to.
Highlight flag
Wire flag bit1 (value 2): the data source requests visual emphasis for an object.
